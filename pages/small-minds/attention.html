Small Minds · Part 2

Paying Attention in One Pass

How RoPE encodes distance as rotation, why FlashAttention never writes its score matrix to VRAM, and how RMSNorm + SwiGLU replaced the 2017 Transformer.

Scroll down to read ↓

Once a sentence becomes a sequence of embedding vectors, each token sits in isolation: the vector for "it" has no idea whether it refers to "cat" or "star" five positions earlier. Self-attention solves that by turning every token into three projections — a Query (what I am looking for), a Key (what I offer), and a Value (what information I pass along if matched) — and blending earlier values in proportion to how strongly their keys align with my query.

Because we are building a language model that predicts the next token, position t is only allowed to look backward at positions 0..t — never into the future. Above, click next head to watch different attention heads specialize: one locks onto subjects, another tracks local syntax, and another bridges long-range pronouns across the sentence.

Step 1 · Position as angleRotary Positional Embeddings (RoPE)

Raw dot products are blind to word order: shuffle the sentence and every query-key score stays identical. Early Transformers added a learned position vector straight onto the token embedding. Modern architectures (Llama, Qwen, DeepSeek) do something far cleaner: Rotary Positional Embeddings (RoPE).

Pair up adjacent dimensions (x₀, x₁), (x₂, x₃), … inside every Query and Key head, and rotate each pair in its 2D plane by an angle proportional to token position t · ω_p, where frequencies sweep geometrically from fast local clocks (ω = 1) down to slow long-range clocks (ω = θ⁻¹). When you take the dot product between query at position m and key at position n, the absolute angles cancel out and leave a function of only their relative distance m − n: 

⟨R(m) q, R(n) k⟩ = qᵀ R(n − m) k   // pure relative distance!

Try moving both query pos m and key pos n upward by the same amount (say from (12, 5) to (20, 13)). All four phasor pairs spin around their circles, yet every green wedge and every cosine score stays locked to the exact same number. And during backpropagation, the gradient through RoPE is trivial: just call the exact same shader with sign = -1.0 to rotate backward.

Step 2 · Online softmaxFlashAttention in one pass

Textbook attention computes S = QKᵀ / √d, writes that entire T × T matrix to GPU memory, reads it back to compute softmax, writes the probabilities out again, and reads them back a third time to multiply by V. For long sequences, those quadratic O(T²) global memory reads dominate everything.

FlashAttention eliminates the T × T matrix completely using online safe softmax. Each GPU thread keeps its query vector plus three tiny running values in on-chip registers: the largest score seen so far m_i, the running exponential sum l_i, and the running weighted value vector O_i. As each new key-value arrives, if a larger score appears we simply rescale the accumulated sum by exp(m_old − m_new) and keep going: 

let m_new = max(m_i, score);
let alpha = exp(m_i - m_new);
let p_ij  = exp(score - m_new);
oAcc = oAcc * alpha + p_ij * V[kt];
l_i  = l_i * alpha + p_ij;
m_i  = m_new;

The readout above isn't a mockup: every time you drag sequence T, our actual flash_attn_fwd WGSL compute shader executes on your GPU and checks its output against exact naive softmax. The maximum numerical difference sits around 10⁻⁷ (pure floating-point rounding), while VRAM traffic drops from O(T²) down to a single scalar log-sum-exp per query row — which is also all we need to recompute probabilities during the backward pass!

Step 3 · Modern blockRMSNorm and SwiGLU

Between attention layers sits the feed-forward network — the model's key-value memory bank. Two quiet upgrades since 2017 make small models train dramatically cleaner:

First, RMSNorm drops mean-centering from LayerNorm and divides each vector only by its root-mean-square length, cutting memory passes in half while keeping activation scales rock-steady. Second, SwiGLU projects the normalized stream through two parallel matrices — a gate passed through SiLU(g) = g · σ(g) and an up path — then multiplies them elementwise so every feature can smoothly switch itself on or off.

Try pushing signal scale to 6× with RMSNorm on: columns 2 and 3 don't even flinch. Now click RMSNorm: OFF and watch the downstream activations explode off the rails. With tiled SGEMM, RoPE, FlashAttention, RMSNorm, and SwiGLU all running in WGSL, we have the complete forward pass of a modern LLM.
